# Fleech — Dokumentation

GitHub zeigt diese Seite automatisch, wenn du den Ordner `docs/` öffnest — auch
in der Handy-App und auch bei einem privaten Repository. Alle Links unten führen
zu Dateien, die GitHub direkt rendert, **ohne Download**.

## Zum Lesen auf dem Handy

| Datei | Was drin steht | Länge |
|---|---|---|
| **[TECHNIK.md](TECHNIK.md)** | Wie Fleech funktioniert — mit Diagrammen. **Fang hier an.** | ~15 Min. |
| [fleech-gesamtkonzept.md](fleech-gesamtkonzept.md) | Die vollständige Fassung: jede Funktion, jede Einstellung, jede Entscheidung samt Begründung | ~2 Std. |
| [../CHANGELOG.md](../CHANGELOG.md) | Was sich Version für Version geändert hat | kurz |

> Die Diagramme sind Mermaid-Blöcke. GitHub zeichnet sie selbst — in der App wie
> im mobilen Browser. Ein PDF muss man dafür nicht laden.
